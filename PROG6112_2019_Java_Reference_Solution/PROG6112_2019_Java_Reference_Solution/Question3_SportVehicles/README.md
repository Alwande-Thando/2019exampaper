# Question 3 — Sport Vehicles
Run `za.ac.prog6112.q3.SportVehiclesApp`. The application reads `cars.txt`, creates one radio button per vehicle, and displays the selected record in the details list. The sample records and values are transcribed from the paper's sample text-file screenshot.

## File format
Each line uses four pipe-separated fields: vehicle name, price, 0–100 seconds, engine size. Keep `cars.txt` in the project root, or use the bundled `src/main/resources/cars.txt`.
